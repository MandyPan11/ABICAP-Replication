# ABICAP-Replication

This repository provides example knowledge graphs and code illustrating how they were used in our paper's simulation setup. It is intended to help readers understand how article materials were represented as knowledge graphs and how those graphs were incorporated into our implementation.

The original ABICAP model can be found here:  [ABICAP repository](https://github.com/sinaris76/ABICAP)

## Background

ABICAP was introduced in the following publication. Please refer to it for a more detailed implementation of ABICAP:

**Rismanchian, S., and Doroudi, S.**  
[*A Computational Model for the ICAP Framework: Exploring Agent-Based Modeling as an AIED Methodology*](https://link.springer.com/chapter/10.1007/978-3-031-36272-9_73)  
International Conference on Artificial Intelligence in Education, July 2023, pp. 792 to 797.

## What this repository contains

- Original article (The kidneys) by Motz et al.(2025) that is replicated in our study (please refer to original_article_with_KCs.md)
- Code demonstrating how these knowledge graphs were implemented in simulation (please refer to knowledge_graph_kidney_LLM.py)
